# Herald — Notifications

In-app notifications demo with a live inbox, unread badge, archive, and toast delivery.

## Features

- Seeded inbox with system, activity, mention, and alert kinds
- Filters for Inbox / Unread / Archived
- Mark read, mark all read, archive, and restore
- Demo composer that pushes events into the inbox and toast stack
- Persistence via `localStorage`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
